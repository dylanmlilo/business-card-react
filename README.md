# Digital Business Card – React

A modern **digital business card / profile card** built using **React, HTML, and CSS**.  
This project showcases a clean, responsive personal profile with contact buttons and social media links, designed for quick sharing and professional presentation.

## ✨ Features

- 📇 Personal profile card layout
- 📧 Email contact button (mailto link)
- 🔗 LinkedIn profile button
- 🌐 Social media icons in footer
- 🎨 Clean, minimal, and modern UI
- 📱 Responsive design
- ♿ Accessible buttons and links

---

## 🛠️ Built With

- **React**
- **HTML5**
- **CSS3**
- **Font Awesome** (icons)

## 🚀 Getting Started

### Prerequisites
- Node.js
- npm or yarn

### Installation

```bash
git clone https://github.com/dylanmlilo/business-card-react.git
cd business-card-react
npm install
npm run dev

The app will run locally on:

http://localhost:5173


(or the port shown in your terminal)

---
```

## 🔗 Usage

Click Email to open the default mail client

Click LinkedIn to visit the LinkedIn profile

Footer icons link to social media platforms
